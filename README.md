# 🤖 Freelance Market Analyzer Bot

Telegram‑бот для анализа рынка фриланс‑услуг.  
Собирает данные о ценах и предложениях, строит статистику и выгружает результат в CSV.

## 📦 Возможности

- 📊 **Сбор данных** – парсинг до 240 услуг (10 страниц) по выбранной категории.
- 📈 **Статистика** – минимальная, максимальная, средняя цена; топ самых дорогих и дешёвых позиций.
- 📁 **CSV‑отчёт** – выгрузка всех собранных услуг в файл.

## 🛠 Технологии

- [TypeScript](https://www.typescriptlang.org/) – типобезопасность.
- [grammY](https://grammy.dev/) – фреймворк для Telegram‑ботов.
- [axios](https://axios-http.com/) – HTTP‑запросы.
- [dotenv](https://github.com/motdotla/dotenv) – управление переменными окружения.

## 🚀 Запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/v1tldev/Freelance-Parser-bot.git
cd Freelance-Parser-bot
```

### 2. Установка зависимостей

```bash
npm install axios dotenv grammy @types/node esbuild tsx typescript
```

### 3. Настройка окружения

Создай файл `.env` в корне проекта:

```
BOT_TOKEN=ваш_токен_бота
BASE_URL=https://kwork.ru
```

- `BOT_TOKEN` – получить у [@BotFather](https://t.me/BotFather).
- `BASE_URL` – базовый адрес сайта.

## 📋 Команды

- `/start` – приветствие и показ главного меню.
- `📂 Категории` – выбрать категорию для анализа.
- `ℹ️ Помощь` – короткая справка.

## 🖼 Пример работы

1. Пользователь выбирает категорию (например, «Чат‑боты»).
2. Бот показывает анимацию загрузки.
3. После парсинга приходит сообщение со статистикой и CSV‑файл.

```
📊 Результаты анализа
▪ Всего услуг: 240
▪ Цены: от 500₽ до 120000₽ (средняя 8450₽)

💎 Самые дорогие:
1. Создам умную автоматизацию N8N — 100000₽
2. Бот в Telegram + гарантия — 12000₽
...

📎 kwork_1740000000.csv
```
